# 발견 — 운영권역(창원·김해)의 2015-01 ~ 2016-06 실거래 데이터가 대부분 비어 있다

**발견 경위**: 2026-08-20, Phase 41 부산 백필 완료 시점을 추정하려고 연도별 거래 분포를
보다가 드러났다. **이 Phase 의 범위 밖이지만 부산보다 중요할 수 있어 근거를 고정해 둔다.**

---

## 실측 근거

### 1. 월별 거래량에 10배 계단이 있다 (창원 5구 + 김해, 6개 구 합계)

| 월 | 거래 | | 월 | 거래 |
|---|---|---|---|---|
| 2015-01 | 286 | | 2016-07 | **2,102** |
| 2015-04 | 272 | | 2016-10 | **2,817** |
| 2015-07 | 221 | | 2017-01 | 1,701 |
| 2015-10 | 263 | | 2018-01 | 1,989 |
| 2016-01 | 207 | | 2020-01 | 2,756 |
| 2016-04 | 192 | | | |

2016-07 을 경계로 약 10배 뛴다. 시장 변화로는 설명되지 않는 크기다.

### 2. 원장이 직접 말해준다

```
창원·김해 molit_trade 2015년 성공 run 수: 12   (기대: 6구 × 12개월 = 72)
```

**2015년은 6개 구 중 1개 구만 수집됐다.** 나머지 5개 구의 2015년, 그리고 2016년 상반기
상당 부분이 애초에 실행된 적이 없다.

### 3. 연도별 비중이 비정상이다

창원·김해 전체 300,974건 중 2015년이 **1.0%**, 2016년이 6.2% 다. 반면 같은 기간을
지금 수집 중인 부산은 2015년만 71,112건(현재까지 적재분의 약 29%)이다. 부산이 더 큰
시장인 것을 감안해도 이 격차는 수집 결손으로밖에 설명되지 않는다.

## 누락 추정 규모

정상 월이 약 2,000~2,800건인데 관측치가 200~290건이므로 약 90% 결손.
18개월 × 약 2,300건 × 0.9 ≈ **3만~4만 건**.

## 영향

10년치 이력을 전제로 하는 기능 전부:

- 단지 상세의 **10년 가격 그래프** — 2015~2016 구간이 사실상 빈 상태로 그려진다
- 랭킹 · 갭 분석 · AI 가격예측의 장기 시계열
- `complex_historical_max` 계열 (신고가 판정)

## 이 발견이 Phase 41 의 판단 하나를 뒤집는다

`41-CONTEXT.md` **D-04** 는 백필 기간을 `--from=201501` 로 정하면서 근거를
*"창원·김해와 대칭으로 맞춘다"* 라고 적었다. **그 전제가 사실이 아니었다** — 창원·김해는
그 구간을 갖고 있지 않다.

결정 자체(201501 부터 수집)는 여전히 옳다. 다만 결과가 예상과 다르다:
**부산이 운영권역보다 더 완전한 데이터를 갖게 된다.**

## 제안 (Phase 41 범위 밖 — 별건)

같은 로컬 병렬 방식으로 창원·김해를 메운다.

```
6개 구 × 18개월(201501~201606) × 2종(apt/villa) = 216 지역-월
```

Phase 41 부산(4,480 지역-월)의 **5%** 규모다. 실측 처리율 3.3행/s · 8병렬 기준
**1~2시간**. `--resume` 이 이미 수집된 12건을 건너뛴다.

⚠️ 실행 전에 확인할 것 — **2015년 이전은 MOLIT API 가 제공하는가.** 부산 백필이
201501 부터 정상 수집된 것으로 보아 2015년은 제공된다. 그보다 이전 연도로 넓힐지는
별도 판단이 필요하다.
