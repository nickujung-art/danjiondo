select min(lat), max(lat), min(lng), max(lng) from complexes where si='부산광역시' and lat is not null;

`src/lib/data/complexes-map.ts`의 라인 87-88 좌표 필터를 실측 결과에 맞춰 확장한다. 부산 동쪽 끝(기장군·해운대 lng ~129.32, 양산 인접 lat ~35.4)을 여유있게 포함하도록, **실측 max가 현재 상한을 넘으면 여유 padding을 더해** 상향한다. 예상 목표값(실측으로 확인 후 조정):
```typescript
.gte('lat', 34.7).lte('lat', 35.8)      // lat 상한은 이미 부산(max ~35.4) 커버 — 실측이 35.8 초과 시에만 조정
.gte('lng', 127.7).lte('lng', 129.4)    // lng 상한 129.3 → 129.4 (부산 기장군·해운대 동쪽 해안 포함)
```
- lng 하한 127.7은 경남 서쪽(하동 등) 기준이라 부산은 그 안에 들어오므로 하한은 유지.
- **실측값이 위 예시와 다르면 실측 기준으로 조정**하되, 상한은 항상 실측 max + 최소 0.05 여유를 둔다.
- 이 파일은 "잘못된 지오코딩 결과 제외" 안전장치이므로 과도하게 넓히지 않는다(예: 129.4 정도, 130까지 확장 금지 — 오지오코딩 필터 기능 유지).
  </action>
