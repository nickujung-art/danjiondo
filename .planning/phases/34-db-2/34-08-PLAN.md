**2. 부산 BBOX 추가 (라인 69, `'합천'` 다음)** — RESEARCH.md 절차: 지오코딩(34-05) 완료된 부산 좌표의 구별 실측 min/max + padding으로 산출. 먼저 실측:
```sql
select gu, min(lat), max(lat), min(lng), max(lng)
from complexes where si='부산광역시' and lat is not null group by gu order by gu;
```
실측 결과로 각 구(또는 인접 구 묶음)마다 padding(약 0.01~0.02)을 더해 `BBOXES` 배열에 항목을 추가한다. 예시 형식(실측값으로 채움):
```typescript
  // 부산 — 34-05 지오코딩 완료 후 구별 실측 min/max + padding
  { name: '부산해운대', latMin: ..., latMax: ..., lngMin: ..., lngMax: ... },
  { name: '부산중부',   latMin: ..., latMax: ..., lngMin: ..., lngMax: ... },
  // ... 16개 구를 구별 또는 인접 구 묶음으로 (zone name은 '부산' 접두어로 경남 zone과 구분)
```
zone name은 `'부산'` 접두어를 붙여 경남 zone 이름과 충돌하지 않게 한다(예 '부산남구' vs 경남엔 없지만 '중구/서구/동구' 같은 일반 구명은 접두어 필수).

**3. `--check-cookie` 프리플라이트 플래그 구현 (D-09)** — RESEARCH.md Code Examples의 `checkCookieValidity()`를 추가하고, `main()` 브라우저/context/page 셋업(라인 282-322) 이후·매핑 루프 진입 전에 `--check-cookie` 분기로 삽입:
```typescript
const SMOKE_TEST_BBOX = { name: '창원북부', lat: 35.26, lng: 128.66 }  // 밀도 높은 기존 zone
async function checkCookieValidity(page: Page): Promise<boolean> {
  const url = `https://new.land.naver.com/complexes?ms=${SMOKE_TEST_BBOX.lat},${SMOKE_TEST_BBOX.lng},14&a=APT&b=A1`
  await page.goto(url, { waitUntil: 'domcontentloaded', timeout: 20_000 }).catch(() => null)
  await page.waitForTimeout(3000)
  if (page.url().includes('nid.naver.com')) return false  // 로그인 리다이렉트 = 만료
  const markerCount = await page.locator('[class*="marker"], [class*="Marker"]').count().catch(() => 0)
  return markerCount > 0
}
```
