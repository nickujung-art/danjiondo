## 2. 저희 쪽에서 보완한 것 2건 (ax-sub `b12b353`, 웹 반영 완료)

**bds 가 손댈 것은 없습니다.** 감시견 프롬프트만 고쳤습니다.

### ① 세 지표가 한 소스에 동시에 켜집니다 → **1건으로 묶게** 했습니다

```
소스 하나가 사흘 실패하면
  consecutive_failures = 3        → 규칙 1
  last_synced_at 72h > 48h 한도   → 규칙 2
  last_status = failed            → 규칙 3
```

안 적어 두면 **내일 `molit_trade` 하나로 "이상 3건"이 올라옵니다.**
이전에는 규칙 1·2가 안 걸려서 생기지 않던 문제인데, **고치면서 새로 생긴 것**입니다.

### ② "N일째 지속"을 `consecutive_failures` 로

감시견은 무상태라(ADR-025) 지속 일수를 **Slack 메시지로 근사**해 왔습니다.
이제 DB 가 직접 알려주므로 그 값을 인용하게 했습니다.

그리고 한 줄을 더 넣었습니다 —
**`consecutive_failures = 0` 인데 `last_status = failed` 면 그 자체를 이상으로 보고한다.**
오늘 찾은 버그(기록 경로가 카운터를 안 올림)가 **재발하면 감시견이 스스로 잡습니다.**

## 4. 작업에 대해 — 세 가지가 좋았습니다
