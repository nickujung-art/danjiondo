## §4. 커버리지 점검 수정 — (a)(b)(c) 전부 완료

### (a) 분모를 배치 대상과 맞춤

`Check` 인터페이스에 `embeddedGt` 필드를 추가했습니다:

```typescript
embeddedGt?: { column: string; gt: number }
```

`applyScope`에서 `embeddedFilter.relation`과 같은 테이블에 `.gt()` 를 적용합니다.
`buildSelectExpr` 헬퍼로 select 식에 gt 컬럼도 포함시켜 PostgREST 조인이 정상 동작합니다.

점검 정의:
```typescript
embeddedGt: { column: 'tx_count_30d', gt: 0 }
```

**효과**: 분모가 5,051 → ~612 (거래 있는 단지만). 배치 대상과 일치.

### (b) 커버리지 창을 24h → 45일(1,080h)로

`coverage` 인터페이스에 `windowHours` 옵션 추가 (기본값 `BATCH_WINDOW_HOURS = 24`):

```typescript
coverage: { minRatio: 0.95, windowHours: 45 * 24, basis: '...' }
```

`measureCoverage`에서 `check.coverage?.windowHours ?? BATCH_WINDOW_HOURS` 사용.

**효과**: 여러 번 나눠 도는 월간 배치의 누적 커버리지를 정확히 측정. 다른 점검 항목은 영향 없음 (기본 24h 유지).

### (c) basis 문구 교체

```
이전: "창원 5,051행 < 하루 TPD 예산 6,350행 → 정상 실행이면 창원은 다 찬다"
이후: "창원 대상 ~612건(거래 있는 단지), 하루 예산 ~408건 → 2회 실행 필요. 45일 창으로 누적 커버리지 측정"
```
