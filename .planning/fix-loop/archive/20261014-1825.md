## 해결 접근법

- 대상: 창원(마산·진해 구지명 포함) → `창원시`, 김해 → `김해시`. 쿼리 4도시 × 3 = 12개.
- 본문 필터(`mentionsTargetCity`)는 1차 거름, **최종 판정은 카카오 주소**(`resolveTargetRegion`):
  주소에 `창원시`/`김해시` 가 있어야 적재. 주소 없음·대상 외 → `[SKIP] 대상 외` 로그 + 카운트.
  단지명으로 지역을 추정하던 폴백 제거.
- `[runstat] job=crawl-presale-news status=ok|failed items=N target=M`
  (items = 감지 단지 수, target = 창원·김해 적재 건수). 감지 0건 조기 종료·검색 전량 실패·예외 경로 모두 출력.
  0건도 정상으로 보고된다.
- 대상 지역을 다시 하드코딩하는 것은 의도: `regions` 는 운영권역보다 넓다(21개 시군 + 부산). CLAUDE.md 운영권역 정본 참조 주석.
