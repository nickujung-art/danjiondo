# 실거래이야기 — 기획안

> 버전 v0.1 · 2026년 7월 기준
> 창부레터(콘텐츠 미디어) 전에 먼저 출시하는 데이터 중심 실거래가 서비스

---

## 한 줄 정의

**증권앱처럼 가볍게, 우리 동네 아파트 실거래가를 확인하는 곳**

---

## 1. 배경 — 왜 이 서비스를 먼저 만드는가

- 창부레터(콘텐츠 미디어 리브랜딩)는 스코프가 커서 기획이 길어지는 중
- 이미 단지온도에 구축된 데이터·기능은 상당 부분 재사용 가능 (신규 개발 아님, UI 재설계 위주)
- 실거래가 데이터만 빠르게 출시해서 카페 회원들에게 먼저 선보이고, 콘텐츠 미디어는 후속으로 이어감
- 브랜드명에 "이야기"를 넣어 창부레터로의 계보를 의도적으로 남김 — 향후 자연스러운 업그레이드/파생 경로

---

## 2. 브랜드

- **이름**: 실거래이야기 (확정)
- **도메인**: 확인 결과 비어있음 (등록 필요)
- **네이밍 의도**: "실거래"(핵심 SEO 키워드, 최다 검색 쿼리) + "이야기"(창원부동산이야기 카페 → 창부레터로 이어지는 브랜드 계보)
- **스타일 참고**: 신한 SOL증권 모바일 (https://open.shinhansec.com/mobilealpha/html/FP/easyGuide.html)
  - 순백 배경, 그림자·그라데이션 없는 완전 플랫
  - 굵은 산세리프 숫자 타이포 (블랙 기본, 상승 빨강/하락 파랑)
  - 카드형 리스트 (좌측 아이콘 + 이름 + 우측 큰 숫자 + 등락 알약뱃지)
  - 세그먼트 토글, 알약형 활성 탭(블루 채움)
  - 액센트 컬러 1개(블루)만 사용, 나머지 그레이스케일
  - CLAUDE.md 기존 UI 금지 규칙(backdrop-blur·gradient-text·glow·보라/인디고)과 방향 일치

---

## 3. 정보구조 (IA)

**하단 탭바 4개** (SOL증권의 MY홈·주식·연금상품·AI 구조 참고, 지도는 별도 탭 없이 검색 결과 내 뷰 옵션으로 통합):

1. **홈** — 오늘 신고가·랭킹 하이라이트 요약
2. **검색** — 단지 검색(자동완성) + 지도 뷰 토글
3. **랭킹** — 거래량·상승률·평당가 TOP
4. **즐겨찾기** — 로그인 필요, 관심 단지 모아보기 + 알림 설정

**단지 상세 페이지 안에 통합** (별도 최상위 탭 아님):
- 10년 그래프·거래내역·시설
- 투자분석(갭투자·사분면) — 직접 분석 제공이 아니라 데이터 노출이라 아직 탭 분리할 변별력 없음 판단
- AI 코멘트(12개월 예측 + Groq 해설)
- 단지 비교(2~4개 비교표)
- 학군(학교알리미 진학률·순위·연락처)
- 관리비(K-apt)

## 5. 운영 범위

- **회원가입/로그인**: 완전 비로그인 열람 원칙 + 즐겨찾기만 최소 로그인 (기존 Supabase Auth 그대로 재사용)
- **어드민 콘솔**: 필요한 것만 축소 — 광고 검수, 분양 관리, 매칭 큐(데이터 오류 대응). 회원관리·카드뉴스·공인중개사 관리는 이 서비스에 없는 기능이라 불필요
- **초기 커버리지**: 창원·김해부터 오픈, 점진 확대 (백엔드는 이미 경남 22개+부산 16개 = 38개 지역 데이터 구축 완료 — 화면 노출 범위만 단계적으로 넓히면 됨)
- **지역별 SEO**: 사이트 브랜드는 지역 중립("실거래이야기" 고정), 개별 페이지 타이틀에서 지역명 노출 (예: "창원시 성산구 아파트 실거래가 | 실거래이야기") — 기존 Phase 23 한글 URL 계층 구조 그대로 재사용
